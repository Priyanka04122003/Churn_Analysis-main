<h1>Customer Churn Analysis</h1>

 📊 Project Overview

This project analyzes customer churn data to identify patterns and factors associated with customer attrition.

The analysis includes data cleaning, exploratory data analysis (EDA), data visualization, and correlation analysis using Python and SQL/SQLite.

<h2>🛠️ Technologies Used</h2>

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL / SQLite
- Jupyter Notebook

<h2>🔍 Key Analysis</h2>

- Customer churn distribution
- Churned vs. retained customers
- Analysis of customer attributes
- Customer escalation vs. churn
- Correlation analysis
- Data visualization
